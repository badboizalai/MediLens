# Style guide

- Stylised medical illustration, not photoreal; no blood, open wounds or dissection imagery.
- Neutral base colours (warm greys/soft beige per system) so the severity palette (BR-020: green/yellow/orange/red/purple + text labels) reads clearly in light and dark modes.
- Skin shell semi-transparent on focus; organs fade in; avoid sudden zooms.
- Contrast: selected region outline ≥ 3:1 against neighbours; hover outline distinct from severity colour.
- Oncology: summary mode first; metastasis markers simple dots/rings, never tumour-like growths.
- Children: same calm style; no frightening imagery.
