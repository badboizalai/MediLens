# Ticket taxonomy

Categories: account/login · upload/capture · extraction wrong · viewer/3D · explanation/content · timeline · sharing · privacy/data rights · security · performance/outage · billing (future) · feedback/idea · other.
Flags: `safety` (wrong medical information, distress, emergency wording, misinterpretation) · `privacy` (access/deletion/consent, worry about data) · `security` (suspicious activity, vulnerability).
Severity S1–S4 per support-model.md; any `safety` class A or `security` exposure is S1.
Fields: id, created_at, channel, category, severity, safety, privacy, security, app_version, unit, input_type, first_response_at, resolved_at, status, linked_backlog, summary (no personal data).
