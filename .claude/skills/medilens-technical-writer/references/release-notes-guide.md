# Release notes guide

User notes (VI + EN): title with version and date · What's new (benefit first) · Improvements · Fixes · Known issues and workarounds · Privacy/safety notes when relevant. No internal jargon, no claims beyond the intended use.

Internal notes: scope (story ids), migrations, feature flags and rollout plan, model/prompt versions (MC ids), config changes, risks and rollback, gate evidence links.

Example (user, EN): "v1.5 — 5 Aug 2027 · New: import PDF and Word records directly, without photos. · Improved: organs that were removed in surgery are now hidden on your body model. · Known issue: some scanned PDFs still need a photo upload."
