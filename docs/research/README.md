# User research kit (S1-T03)

Kit for the 5-8 patient/caregiver and 1-2 clinician interviews (plan §2.5). The kit is prepared by the BA role; **interviews, recruitment, signed consent and real notes are done by humans**. Nothing here contains interview results.

| File | Purpose |
| --- | --- |
| [research-plan.md](research-plan.md) | Goals, questions, participants, schedule, data handling |
| [interview-guide.md](interview-guide.md) | 45-min semi-structured guide (VI + EN gloss) |
| [consent-form.md](consent-form.md) | Consent VI + EN (DRAFT, needs REG review) |
| [note-template.md](note-template.md) | De-identified note structure (one per participant) |
| [anonymisation-checklist.md](anonymisation-checklist.md) | Checks before any note is stored |
| [recruitment-tracker.md](recruitment-tracker.md) | Codes-only tracker |

Rules: participants appear only as `P01`, `P02`... (clinicians `C01`...). Never commit names, phone numbers, emails, record numbers, audio or video. Raw recordings and the code-to-person key stay outside the repo (see the data-handling plan). MediLens illustrates and explains; interviews must not turn into medical advice (BR-042).
